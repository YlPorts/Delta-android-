# Audit of the existing native port

Baseline: `4e3a0a030966cc01662c47462cf66c89059751d5`, branch `android/native-bootstrap`.
The original iOS tree and all 37 Android commits are preserved.
GitHub Actions run 39379018386 passed and produced the 0.2.0-dev ARM64 debug APK.
A build success alone is not runtime verification.

## Findings before changes

- JNI hosts real libretro Gambatte, not UIKit/DeltaCore. Fixed 160x144 framebuffer;
  other systems are not integrated. Callbacks and core state have no native lock.
- SRAM truncates its destination before a successful write. RTC memory is omitted.
  Restore silently ignores invalid lengths. Raw states only compare byte length;
  they do not bind the ROM or core binary or verify integrity.
- Lifecycle resumes emulation in `onResume` even while the pause/state menus are
  open. Rotation is consumed without rebuilding the library/settings layout.
- Palette generation searches `Delta`, but actual catalogs are in `Resources`.
  Purple uses integer components and LightPurple uses hexadecimal components,
  neither accepted by the old parser. All three colors fall back to guesses.
- Library cover frames are 90x100.8 instead of the original maximum 90x90;
  margins do not implement GridCollectionViewLayout's equal spacing formula.
  Missing covers and navigation/settings icons are substituted graphics/text.
- Settings rows are separate rounded cards instead of inset grouped sections;
  labels/details, heights and navigation differ from Settings.storyboard.
- Pause is an Android AlertDialog list, without original grid artwork or blur.
- Skins import one GBC package, deleting the previous file before replacement.
  No bundled Standard.deltaskin. `gameScreenFrame`, legacy representation nesting,
  default screen placement and per-edge inherited hit padding are misinterpreted.
  A portrait control-only skin is incorrectly centered over the game screen.
  PNG decode has no decoded-pixel limit; PDFs and package reads need bounds.
- Audio and frame timing use a hardcoded GB rate; no real audio-focus handling.
  Physical keys work but analog joystick axes are omitted. No runtime tests.
- CI fetches a moving Gambatte HEAD, has no source/license bundle, runtime tests,
  APK ELF/16KB alignment checks, visual captures or failure report artifacts.

## Inspected original reference

`Delta/Base.lproj/{Main,Settings,PauseMenu}.storyboard`, game selection controllers,
GridCollectionViewCell/Layout, PauseViewController/GridMenuViewController,
SettingsViewController, ControllerSkinsViewController, Theme, UIColor+Delta,
`Resources/Assets.xcassets`, and DeltaCore ControllerSkin/ControllerView.
The checked-in reference is Delta **2.0b5 (163)**. It has iOS-version-specific UI;
Android's initial target is the UIKit grid presentation used before iOS 26.
No claim of iOS 26 Liquid Glass parity or measured 1:1 fidelity is made.

## Engine inventory (original submodule revisions)

| System | Original source | Android baseline |
| --- | --- | --- |
| GB/GBC | GBCDeltaCore / Gambatte | Real libretro Gambatte, untested at baseline |
| NES | NESDeltaCore / vendored Nestopia, including libretro/JNI | Not integrated |
| GBA | GBADeltaCore / VBA-M | Not integrated |
| SNES | SNESDeltaCore / Snes9x | Not integrated |
| Genesis | GPGXDeltaCore / Genesis Plus GX | Not integrated |
| N64 | N64DeltaCore / mupen64plus, GLideN64, rsp-hle | Not integrated |
| DS | MelonDSDeltaCore / melonDS | Not integrated |

The original wrappers depend on Objective-C/UIKit/DeltaCore and need native
Android adapters, not a direct UIKit build. All seven systems remain in scope.
Delta Sync interoperability, N64 GPU/ARM64 paths, DS firmware/touch/microphone/3D,
and real Galaxy A15/Android 16 performance require separate verification.

## Verified during this continuation

- Local Java 17/Gradle: ARM64 application and instrumentation APK compilation,
  lint, APK v2 signature verification and 16KB ZIP/ELF checks passed.
- Three Python resource tests passed: exact colors, rejected invalid components,
  and byte-identical original images/skin archives against source hashes.
- Production-host ASan/UBSan tests passed for authored GB, GBC, MBC3/RTC and NES
  programs: CPU, changing video, non-silent PCM, actual joypad reads, SRAM/RTC,
  save/load, corruption/wrong-ROM rejection, legacy state reading and cleanup.
- Original Nestopia built successfully for ARM64 with the original GNU C++98
  dialect; the first attempt with the newer NDK default correctly exposed
  narrowing errors. No feature was removed to make that build succeed.
- Original LFS batch retrieval failed (SSH unavailable; installation permissions
  rejected HTTPS batch). Public GitHub media retrieval succeeded, and each object
  was verified against its original LFS SHA-256 and length before packaging.
- Local Gradle initially lacked proxy settings/a full JDK. Proxy/CA trust and an
  actual Java 17 JDK were configured in the task workspace; repository dependency
  security checks and TLS validation were retained.

Android instrumentation/visual captures on CI, matched iPhone comparisons, and
physical Galaxy A15 tests must be assessed separately; the host tests above are
not evidence that those checks passed.
